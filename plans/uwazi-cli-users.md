# Plan: Uwazi CLI — users slice (issue #9694)

PRs: **A** = Steps 1–2 · **B** = Step 3 · **C** = Steps 4–6 · **D** = Steps 7–10. `settings` / `tenants` commands are separate PRs.

Locked decisions (do not re-open):
- Binary `uwazi`, source in `apps/cli`, depends on `app/api/core` only (never the reverse).
- CLI actor = `User.system()` (`app/api/users.v2/model/User.ts`), not `PUBLIC_USER_ID`.
- Tenant `domain` read from tenant context (`ExecutionContext.tenant.domain`), protocol `https`; empty domain → error.
- `--all-tenants` only on queries; writes target one tenant.
- Exit codes: `0` ok · `1` unexpected · `2` validation · `3` not found · `4` conflict · `5` rule violation · `130` interrupted.
- create on existing → conflict; delete on missing/already-deleted → not found. No idempotency flags.
- `--role` required on create. `users update` is a partial update (undefined = untouched, null = clear, only for optional fields).
- HTTP behaviour must not change anywhere (`app/api/utils/handleError.js` stays `instanceof`-based).
- Domain invariants use zod inside domain objects.
- Audit: no implementation, but pipeline has a middleware slot for it.

## Step 1: Create ExecutionContextFactory

**Files:** app/api/core/infrastructure/factories/ExecutionContextFactory.ts, app/api/core/infrastructure/factories/specs/ExecutionContextFactory.spec.ts, app/api/core/libs/ExecutionContext.ts

**Skeleton:**
```ts
type TelemetryKind = 'http_request' | 'queue_job' | 'migration' | 'cli' | 'v1_bridge';

type ExecutionContextOptions = {
  tenant?: Tenant;
  actor?: User;
  correlationId?: string;                       // not generated by default (keeps behaviour)
  telemetry: { kind: TelemetryKind; startPerfMs?: number };
  overrides?: Partial<DependencyFactories>;
};

class ExecutionContextFactory {
  static defaultFactories(telemetry: ExecutionContextOptions['telemetry']): DependencyFactories
  static build(options: ExecutionContextOptions): ExecutionContextDeps
  static run<R>(options: ExecutionContextOptions, fn: () => Promise<R>): Promise<R>
  static runForTenant<R>(tenantName: string, options: Omit<ExecutionContextOptions, 'tenant'>, fn: () => Promise<R>): Promise<R> // wraps legacy tenants.run
}
```

**Do:**
- Defaults = today's block: `...transactionManagerFactories()`, `JobsDispatcherFactory.default`, `EventEmitterFactory.default`, `IdGeneratorFactory.default`, `LoggerFactory.default`, `new TelemetryCollector(kind, startPerfMs)`; `overrides` spread last.
- `build` returns the plain `Context` (needed by `ExecutionContext.attachContext` in the queue worker).
- `runForTenant` sets both `tenants.run` and `ExecutionContext.run` (same as `runInJobContext`).
- Factory never resolves actors and never checks for an existing store (reentrancy stays with callers).
- Export `DependencyFactories` type from `ExecutionContext.ts`; switch `PostgresTransactionManager` / `MongoTransactionManager` imports to `import type` if only used as types.

**Test:** spec covering defaults present, overrides win, tenant/actor/correlationId propagated, `runForTenant` sets `tenants.current()` and `ExecutionContext.tenant` — run `yarn test app/api/core/infrastructure/factories/specs/ExecutionContextFactory.spec.ts`

**Skeleton:**
```ts
type ErrorCategory = 'validation' | 'not_found' | 'conflict' | 'rule_violation';

abstract class DomainError extends Error {
  readonly code: string;
  readonly category: ErrorCategory;            // default 'rule_violation'
  asObject(): { name; code; category; message; stack; cause }
}

abstract class ConflictError extends DomainError {}   // category 'conflict'
abstract class ValidationError extends DomainError {} // category 'validation' (existing class)
```

**Test:** unit spec for category defaults/subclasses; update `app/api/core/domain/user/specs/errors.spec.ts`; confirm HTTP unchanged with `yarn test app/api/utils/specs/handleError.spec.js app/api/core/infrastructure/express/users`

```ts
const UserProfileSchema = z.object({
  username: z.string().trim().min(1).refine(u => !u.includes(' '), 'Usernames can not contain spaces.'),
```
